# 🛡️ AI Guardian X

AI Guardian X is an AI-assisted Android security application focused on behavioural analysis, privacy protection, and intelligent mobile security.

## ✨ Features

- 🧬 Behaviour DNA – Typing, swiping and touch-pattern analysis
- 📞 Deepfake Call Protection – Suspicious call monitoring and simulation
- 🔧 Self-Healing – Security issue analysis and recovery support
- 🕵️ Privacy Twin – Privacy scoring and scanning
- 🚨 Emergency Lock – Quick device protection
- ⚙️ Security Controls – Biometric, threat detection and security alerts
- 🌙 Light & Dark Mode

## 🛠️ Tech Stack

- Kotlin
- Jetpack Compose
- Android SDK
- Google AI Studio
- Android Studio

## 🎯 Objective

To explore AI-assisted mobile security through behavioural intelligence, privacy awareness, and Android security capabilities.

## 👩‍💻 Project Status

Currently under development as an academic AI/ML project.
